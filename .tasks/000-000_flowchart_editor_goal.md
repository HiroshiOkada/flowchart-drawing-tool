# ゴール定義: フローチャートWebアプリケーション

## 最終目標
ブラウザ上でフローチャートやダイアグラムの編集・印刷・保存ができる高品位なWebアプリケーション（SPA）を構築し、GitHub Pagesにデプロイ可能な状態にする。

## 完成要件チェックリスト
- [ ] 1. 図形（長方形、ひし形、両端半円長方形）の描画・D&D移動・リサイズ・スタイル変更
- [ ] 2. 直線・矢印コネクタの描画・アンカーポイント接続・線上ラベル
- [ ] 3. エディタ UI/UX（ダークテーマ、A4サイズ領域、Undo/Redo、インラインテキスト編集）
- [ ] 4. データ操作（LocalStorage自動保存、JSON保存・読込、高解像度PNG出力）
- [ ] 5. 印刷最適化（@media print / @page によるA4 1ページ完全フィット・白背景化・画面UI非表示）
- [ ] 6. TypeScript型安全、モジュール分離、コアロジック単体テスト
- [ ] 7. GitHub Pagesデプロイ手順記載の README.md とビルド確認
